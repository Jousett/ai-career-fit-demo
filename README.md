# AI Career Fit & Resume Focus

A small learning project exploring how AI can support career decision-making without replacing human judgment.

## What it does
- Accepts a job description and a candidate profile.
- Performs a simple local keyword-overlap scan in the browser.
- Surfaces shared terms and potential gaps to verify.
- Generates a structured prompt for a deeper AI-assisted fit analysis.
- Emphasizes truthful tailoring: no invented experience, and hard requirements are separated from preferences.

## Why I built it
I use AI as a practical thought partner for organizing information, comparing job requirements, improving communication, and reducing repetitive work. I wanted a simple tool that demonstrates that workflow in a transparent way.

## How to run it
Open `index.html` in any modern browser. No installation and no API key are required.

## What I’m learning
- Prompt design
- Human-in-the-loop AI workflows
- Responsible use of AI in career decisions
- Lightweight browser automation and text analysis
- How to turn ambiguous information into a repeatable decision process

## Privacy
Everything in the demo runs locally in the browser. The project does not upload or store pasted text.

## Next steps
Possible future improvements include structured scoring, configurable hard requirements, resume-section suggestions, and optional connection to an LLM API.
